# Recetas peruanas — repo de ejemplo

Repositorio de demostración: una mini colección de recetas en Markdown y una página web simple que las muestra.

## Estructura

```
.
├── README.md        ← esta portada
├── index.html       ← página web que lista las recetas
└── recetas/
    ├── ceviche.md
    ├── causa-limena.md
    └── chicha-morada.md
```

## Cómo verlo

- **En GitHub:** abre la carpeta `recetas/` y haz clic en cualquier archivo.
- **En tu compu:** clona el repo y abre `index.html` en el navegador.

```bash
git clone https://github.com/suarezladriana/ejemplo-recetas.git
cd ejemplo-recetas
open index.html
```

## Cómo contribuir

1. Haz un *fork* del repo.
2. Agrega tu receta como `recetas/nombre-de-la-receta.md` (usa una existente como plantilla).
3. Abre un *pull request*.
